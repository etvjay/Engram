# Base Partner Contract

Class: `PUBLISHED_BONUS`

## Published qualification
A claimed Base stack counts only when judges can see it doing real work in the product. Deployment is the eligibility floor; an executed onchain action shown in the demo earns the partner bonus, including wallet operation, x402 payment, B20 read, or contract interaction.

## Engram fit
Best use: recalled execution memory changes an economically consequential action, e.g. provider/payment terms, route choice, or x402 capability purchase.

## Veto
Do not add Base merely for a transaction receipt. The onchain action must be downstream of the remembered decision.

## Required evidence
- protocol-native transaction/receipt;
- action visible in demo;
- trace linking recalled memory -> changed decision -> Base action.

## Negative test
Remove the Base action. If product meaning is unchanged, do not claim the partner stack.

Status: `UNVERIFIED / OPTIONAL`.
